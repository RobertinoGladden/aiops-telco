SERVER CONFIGURATION

Enable network intelligence

Set the values in .env, then restart the Integration Hub. Provider credentials stay on the server. 

AI_ENABLED=true
GROQ_API_KEY=...
OPENAI_API_KEY=...
GROQ_MODEL=openai/gpt-oss-20b
DECISION_MODEL=gpt-6-luna

Analysis runs when an operator selects Analyze with AI. Selected incident facts are sent to both providers.

OPERATIONAL WORKFLOW

Connect your operational workflow

Connect n8n, an AWX gateway, or your operations backend through an endpoint that accepts Idempotency-Key. 

WORKFLOW_ENABLED=true
WORKFLOW_WEBHOOK_URL=...
WORKFLOW_WEBHOOK_TOKEN=...

Strata queues a review request. Your operational workflow handles approval and runbook execution.

The default 0.85 threshold is a starting point. Calibrate it against labeled field incidents.
